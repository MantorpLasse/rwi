# ADR-0001

## RWI Philosophy

Status

Accepted

Date

2026-07-17

---

## Decision

RWI is not a database.

RWI is an intelligence platform.

The database exists to support intelligence.

The goal is not to store data.

The goal is to transform verified information into explainable intelligence.

---

## Consequences

Every piece of information must have a source.

Every source must be preserved.

Every score must be explainable.

History is never deleted.

Documents are first-class citizens.
