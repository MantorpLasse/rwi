# Public UI visual redesign plan

## Problem

The candidate UI is technically safe but visually relies on bordered cards,
tables, and pills to communicate almost every hierarchy level. This makes the
dashboard read as an admin workspace and airport pages as database records.

## Direction

Use an editorial aviation-intelligence language: large typographic identity,
quiet sectional rules, compact evidence metadata, and deliberate whitespace.
Gold is reserved for identity/action; semantic colours remain classification
signals rather than decorative surfaces.

## Composition

- **Dashboard:** remove hero media; introduce a type-led title with a subtle
  CSS runway-line motif. Metrics become borderless indicators. Activity and
  selected Signals become compact intelligence rows. The timeline remains the
  substantial analytical visual.
- **Airport:** create an airport-profile header and an integrated runway rail.
  Current EMAS, projects, timeline, and history become full-width editorial
  sections separated by rules, not nested cards.
- **Signals:** retain filtering and density but emphasize airport code and
  title; reduce column/table chrome and recede secondary metadata.
- **Signal detail:** use a single intelligence-brief flow with aligned facts
  and an evidence/source section.

## Responsive behavior

Desktop uses a profile rail and aligned intelligence rows. Mobile collapses
to a natural reading sequence; no horizontal table metaphor or hero media is
introduced. Native disclosures remain keyboard-accessible.
